# Cart2Insights

Objective

The objective of this project is to analyze the e-commerce data and uncover meaningful business insights related to sales, customers, products, sellers, payments, delivery performance, and customer satisfaction.

Project Objectives

- Analyse overall sales and order performance.
- Understand customer behaviour and satisfaction.
- Identify top-performing products and sellers.
- Evaluate delivery performance.
- Generate meaningful business insights.

Technologies Used

- Python
- Pandas and NumPy
- MySQL
- SQLAlchemy
- Matplotlib and Seaborn
- Streamlit
- Jupyter Notebook

Dataset

The project uses nine CSV datasets covering customers, orders, order items, products, sellers, payments, reviews, geolocation and product category translations.

Project Workflow

1. Data loading and understanding.
2. Data quality checks and cleaning.
3. Database design and MySQL connection.
4. Feature engineering.
5. Exploratory Data Analysis (EDA).
6. Statistical analysis.
7. Interactive dashboard development using Streamlit.

Final Output

An interactive analytics dashboard that provides insights into e-commerce sales, customers, products, payments, reviews and delivery performance.
